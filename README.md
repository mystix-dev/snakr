# DAMNBRUH UI Clone (Teal/Violet Theme)

This is a front-end layout clone of the provided screenshot:
- Top welcome + login button
- Center logo/title
- 3-column dashboard layout:
  - Left: Leaderboard + Friends
  - Center: Join Game panel + Manage Affiliate
  - Right: Wallet + Customize

## Run locally
Just open `index.html` in your browser.

## Customize colors
Edit `:root` in `styles.css`:
- `--acc1` teal
- `--acc2` violet
- `--acc3` cyan
